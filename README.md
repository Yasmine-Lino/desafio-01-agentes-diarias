# Desafio 01 — Instrução de Pedidos de Diárias

Projeto individual de **Yasmine Lino Franco** ([Yasmine-Lino](https://github.com/Yasmine-Lino)), FIC DEV IA — Agentes Autônomos.

O projeto simula a instrução de 12 pedidos de diárias da SEMA-MT e duas complementações. Os dados e a Instrução Normativa SEMA nº 07/2026 são hipotéticos. Um único agente Agno consulta ferramentas Python, produz uma instrução estruturada e passa por uma verificação independente antes da conferência humana. A decisão administrativa cabe ao ordenador de despesa.

## Como começar

Siga o [LEIA-ME](LEIA-ME.md) para instalar e executar o projeto no Windows (PowerShell), Linux (Bash) ou macOS (zsh/Bash), configurar a API, executar os testes offline e preparar a interface Streamlit. O ambiente foi validado no Windows; os comandos para Linux e macOS ainda precisam de validação nessas plataformas. As operações protegidas exigem autenticação OIDC e configuração do servidor.
